# Тексты интерфейса

Задача #35, требование R10. Тексты собраны по [карте экранов](../flows/screen-map.md) (#8) и сверены с текущими страницами `web/src`. Раздел на каждый экран карты: заголовки, кнопки, подсказки, ошибки и пустое состояние. Сам текст — в обратных кавычках, после тире — где он стоит.

Тон проверяет тест `tests/acceptance/35-ui-copy.test.mjs`.

## Правила тона

- Обращаемся на «вы», спокойно и коротко. Без восклицательных знаков, канцелярита и английских слов.
- Кнопка — глагол, что произойдёт: `Отправить обращение`, `Назначить`. До четырёх слов, без точки в конце.
- Ошибка говорит, что сделать: `Выберите категорию.` Не «Неверный ввод» и не «Ошибка 422». Заканчивается точкой.
- Пустое состояние объясняет, почему пусто, и даёт следующий шаг: кнопку или подсказку.
- Загрузка — существительное с многоточием: `Загрузка очереди…` (символ «…», не три точки).
- Кавычки только «ёлочки». Номер обращения всегда в виде A-0XX.
- Имитацию называем имитацией: бейдж `Имитация` и пояснение, что именно не настоящее.

## Общие тексты

Используются на нескольких экранах; в разделах экранов не повторяются.

| Где | Текст |
|---|---|
| Загрузка данных | `Загрузка…` с уточнением: `Загрузка обращения…`, `Загрузка очереди…`, `Загрузка сводки…` |
| Ошибка загрузки | `Не удалось загрузить данные. Можно повторить запрос.` + кнопка `Повторить` |
| Сервер недоступен | `Нет связи с сервером. Проверьте, что демо запущено, и повторите.` |
| Слишком много запросов | `Слишком много запросов, повторите через 5 с` |
| Отправка | кнопка на время запроса: `Отправка…` |
| Статусы | `Новое`, `На рассмотрении`, `В работе`, `Ожидает уточнения`, `Реализовано`, `Закрыто`, `Отклонено` |
| Типы | `Проблема`, `Предложение`, `Благодарность` |
| Просрочка | `Просрочено · срок 12.11` (значок и текст, не только цвет) |
| Бейдж имитации | `Имитация` с подсказкой, что именно не настоящее |

## Демонстрационная роль (`roles`)

### Заголовки

- `Модус Трейд` — логотип в шапке
- `Обратная связь сотрудников` — подпись под логотипом

### Кнопки

- `Демонстрационная роль` — подпись переключателя роли
- `Сотрудник` — вариант роли
- `Руководитель` — вариант роли
- `Администратор` — вариант роли
- `Подсказки демо` — флажок подсказок шагов
- `О прототипе` — ссылка в нижней панели
- `Перейти к содержимому` — скрытая ссылка для клавиатуры

### Подсказки

- `Выбор роли — не настоящий вход, пароля и учётной записи нет.` — всплывающая подсказка у переключателя
- `Демонстрация · только синтетические данные. Выбор роли имитирует вход.` — нижняя панель
- `Шаг 3: переключите роль на «Руководитель» и откройте обращение в очереди.` — подсказка демо, пример

### Ошибки

- `Этот раздел доступен другой роли. Вы в своей рабочей области.` — после попытки открыть чужой маршрут
- `Страница не найдена. Вернитесь к обращениям по кнопке ниже.` — неизвестный адрес, кнопка `Вернуться к обращениям`

### Пустое состояние

- `Роль не выбрана. Выберите роль в шапке, чтобы начать демонстрацию.` — если сохранённая роль сброшена

## Новое обращение (`submit`)

### Заголовки

- `Обратная связь` — надзаголовок
- `Новое обращение` — заголовок
- `Сообщите о проблеме или предложите улучшение. Обращение видят вы, руководители и администраторы.` — вводный текст

### Кнопки

- `Отправить обращение` — основная кнопка
- `Отправка…` — та же кнопка во время запроса, неактивна
- `Добавить тестовое вложение` — флажок

### Подсказки

- `Тип обращения` — подпись поля: `Проблема`, `Предложение`, `Благодарность`
- `Категория` — подпись поля, первый пункт `Выберите категорию`
- `Описание` — подпись поля: что случилось и где
- `Предлагаемое решение (необязательно)` — подпись поля
- `Файл-заглушка sample-request.txt: сохраняются только название, тип и размер, содержимое не загружается.` — под флажком вложения, рядом бейдж `Имитация`
- `Категория без ответственного (демо)` — пункт списка для шага 2 демо

### Ошибки

- `Выберите категорию.` — категория не выбрана
- `Опишите проблему или предложение.` — пустое описание
- `Описание слишком длинное: сократите до 4000 символов.` — превышен предел длины
- `Не удалось отправить обращение. Введённый текст сохранён, повторите отправку.` — ошибка сервера

### Пустое состояние

- `Категории не загрузились. Нажмите «Повторить», введённый текст не потеряется.` — нет списка категорий

## Обращение зарегистрировано (`registered`)

### Заголовки

- `Отправлено` — надзаголовок
- `Обращение зарегистрировано` — заголовок
- `Обращение A-0XX зарегистрировано.` — текст с номером

### Кнопки

- `Открыть обращение` — основная
- `К моим обращениям` — вторичная

### Подсказки

- `Ответственный: Руководитель закупок · срок 14.11` — кому передано и до какого числа
- `Следующий шаг: ответственный рассмотрит обращение и ответит в карточке.` — что будет дальше

### Ошибки

- `Номер не получен. Откройте «Мои обращения»: если обращения там нет, отправьте форму ещё раз.` — ответ сервера без номера

### Пустое состояние

- `Ответственный пока не назначен: обращение в запасной очереди, руководитель назначит его вручную. Откройте обращение, чтобы следить за статусом.` — категория без ответственного (шаг 2)

## Карточка автора (`author`)

### Заголовки

- `Обращение` — надзаголовок
- `A-0XX · Проблема · Межотдельное взаимодействие` — заголовок карточки
- `Следующий шаг` — блок подсказки
- `Итог рассмотрения` — блок решения
- `Дальнейшие действия` — подзаголовок в итоге
- `Комментарии` — блок переписки
- `История обращения` — блок истории

### Кнопки

- `К моим обращениям` — ссылка назад
- `Ответить на уточнение` — отправка ответа
- `Обновить карточку` — перечитать данные

### Подсказки

- `Ответственный`, `Создано`, `Срок` — подписи полей
- `Ожидает назначения` — вместо имени ответственного
- `Ваш ответ на уточнение` — подпись поля ответа
- `Сохранены только сведения о файлах-заглушках, содержимое недоступно.` — у тестовых вложений
- `Руководитель ждёт ваш ответ. Ответьте в поле ниже.` — следующий шаг при статусе «Ожидает уточнения»
- `Ответ на уточнение отправлен.` — сообщение после отправки

### Ошибки

- `Введите ответ на уточнение.` — пустой ответ
- `Обращение недоступно. Вернитесь к своим обращениям.` — чужое или удалённое обращение

### Пустое состояние

- `Комментариев пока нет. Вопросы руководителя и ваши ответы появятся здесь.` — нет переписки
- `Решения пока нет. Вы увидите итог здесь, когда руководитель закроет обращение.` — вместо блока итога

- `Сбросить` — сброс фильтров
- `Назад` — пагинация

### Подсказки

- `Подразделение`, `Категория`, `Статус`, `Очередь` — подписи фильтров
- `Все подразделения`, `Все категории`, `Все статусы`, `Все обращения` — значения по умолчанию

### Пустое состояние

- `По выбранным фильтрам обращений нет.` — текст
- `Измените условия или нажмите «Сбросить», чтобы увидеть всю очередь.` — подсказка

## Карточка руководителя (`handling`)

### Заголовки

- `Обработка обращения` — блок действий
- `Назначение` — подблок
- `Статус и обсуждение` — подблок
- `Завершение` — подблок итога

### Кнопки

- `К очереди` — ссылка назад
- `Назначить` — назначение ответственного
- `Начать рассмотрение` — смена статуса
- `Взять в работу` — смена статуса
- `Вернуть на рассмотрение` — смена статуса
- `Добавить комментарий` — комментарий
- `Запросить уточнение` — вопрос автору
- `Зафиксировать итог` — решение или отказ
- `Обновить карточку` — перечитать данные

### Подсказки

- `Назначить ответственного` — подпись списка, первый пункт `Выберите руководителя`
- `Комментарий или вопрос` — подпись поля
- `Итог рассмотрения` — подпись списка: `Реализовано` или `Отклонено`
- `Обоснование решения` — подпись поля, обязательно
- `Дальнейшие действия (необязательно)` — подпись поля
- `Автор увидит обоснование в своей карточке. При отказе объясните причину.` — подсказка к итогу
- `Ответственный назначен.`, `Статус обращения изменён.`, `Комментарий добавлен.`, `Запрос уточнения отправлен автору.`, `Итог рассмотрения зафиксирован.` — сообщения об успехе

### Ошибки

- `Выберите ответственного.` — не выбран руководитель
- `Введите текст сообщения.` — пустой комментарий или вопрос
- `Объясните решение или причину отказа.` — пустое обоснование
- `Статус уже изменил другой руководитель. Обновите карточку.` — конфликт изменений

### Пустое состояние

- `Ответственный не назначен. Выберите руководителя и нажмите «Назначить».` — обращение из запасной очереди
- `Комментариев пока нет. Добавьте комментарий или запросите уточнение у автора.` — нет переписки

## Сводка (`summary`)

### Заголовки

- `Обзор обратной связи` — надзаголовок
- `Сводка` — заголовок
- `Результаты рассмотрения и темы, к которым сотрудники возвращаются чаще.` — вводный текст
- `Всего обращений`, `Доля закрытых`, `Среднее время первого ответа` — карточки показателей
- `Обращения по типам` — график
- `Повторяющиеся темы` — таблица

### Кнопки

- `Обновить сводку` — перечитать показатели
- `Открыть в очереди` — переход к теме (нужна роль руководителя)

### Подсказки

- `Сводка на 10.11, 18:00` — время данных
- `За всё время` — подпись к числу обращений
- `По 12 обращениям с первым ответом` — подпись к среднему времени
- `Категории, в которых есть минимум два обращения.` — пояснение к повторяющимся темам
- `Повторяется 5 раз` — счётчик темы

### Ошибки

- `Не удалось загрузить сводку. Повторите попытку.` — ошибка загрузки, кнопка `Повторить`
- `Очередь доступна руководителю. Переключите роль на «Руководитель».` — после «Открыть в очереди» у администратора

### Пустое состояние

- `Обращений пока нет — диаграммы появятся после первой подачи.` — нет данных
- `Нет ответов` — вместо среднего времени, подсказка `Показатель появится после первого ответа руководителя`
- `Повторяющихся тем пока нет.` — нет повторов
