# Иконки интерфейса и слайдов

Единый набор SVG без внешних библиотек. Иконка дублирует смысл цвета и подписи, чтобы статус был понятен и без цвета (например, при дальтонизме или печати в ч/б).

Все иконки нарисованы линией на сетке 24×24, `fill="none"`, `stroke="currentColor"`, толщина линии 2. Цвет наследуется от текста вокруг, поэтому иконка сама подстраивается под светлую и тёмную тему и под цвет статуса.

Посмотреть все иконки разом: откройте `preview.html` в браузере. После правки SVG пересоберите его командой `node design/assets/icons/build-preview.mjs`.

## Размеры

- **16 px**: внутри бейджей, строк таблицы и подписей рядом с текстом 14 px. Ставьте `width="16" height="16"`, линия визуально остаётся читаемой.
- **20 px**: в кнопках и пунктах меню.
- **24 px**: базовый размер, в заголовках карточек и пустых состояниях.
- **32–48 px**: только на слайдах и в иллюстрациях пустых экранов.
- Размер меняется атрибутами `width`/`height` или CSS, `viewBox` не трогаем. Толщина линии не масштабируется отдельно.
- Иконка рядом с текстом идёт с отступом 4–6 px и выравнивается по центру строки.

## Правила

- Только `currentColor`, без жёстко заданных цветов, градиентов, `<image>`, `<use>`, внешних ссылок и скриптов (это проверяет тест `tests/acceptance/107-icons.test.mjs`).
- В каждом файле есть `<title>` с русской подписью из контракта (`x-labels`). Если иконка стоит рядом с видимым текстом, в разметке ставьте ей `aria-hidden="true"`, чтобы подпись не читалась дважды.
- Подключение иконок в код веба делается отдельной задачей по вёрстке.
