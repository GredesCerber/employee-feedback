# Расширенная сводка (#124)

`GET /summary` доступен только демо-администратору (`X-Demo-User: admin-1`).
Прежние поля и формулы сохранены. Три дополнительных поля соответствуют `contracts/api.yaml`:

- `byDepartment` содержит все подразделения справочника, включая пустые, по возрастанию `departmentId`. `count` — все обращения; `closedCount` — реализованные, отклонённые и закрытые; `closedShare` — их доля от 0 до 1, либо 0 при пустой группе.
- `avgResolutionHoursByCategory` содержит все категории по возрастанию `categoryId`. Среднее в часах считается как `closedAt - createdAt` только для завершённых обращений с заполненным `closedAt`. `closedCount` здесь — число записей в этом среднем; при отсутствии таких записей среднее `null`, счётчик 0.
- `overdueCount` считает незавершённые обращения, у которых `dueAt < generatedAt`, в том числе без ответственного. Ровно в момент срока обращение ещё не просрочено. Используется время текущего ответа, а не сохранённый флаг `overdue`.

Пустое хранилище возвращает нулевые счётчики и доли, `null` для средних и все известные группы. Расчёт ничего не изменяет в обращениях. Даты и показатели начального набора синтетические; это не оценка работы реальных сотрудников.

Проверка: `npm --prefix api run build`, затем `node --test tests/acceptance/124-api-summary-breakdowns.test.mjs`. Приёмка проверяет контракт ответа, ручной пересчёт seed, прежние значения, права, пустые группы, среднее только по завершённым и границу просрочки на управляемых часах.
