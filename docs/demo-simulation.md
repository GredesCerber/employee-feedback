# Демо-симуляция «живого сервиса»

Фоновый процесс `scripts/demo-sim/` ходит в работающий API по HTTP и ведёт себя как люди: сотрудники подают обращения,
руководители берут в работу, отвечают, запрашивают уточнение, решают или отклоняют, изредка откатывают действие.
Рядом с интерфейсом виден журнал событий, растёт очередь, меняются статусы, приходят уведомления.

## Как включить

Симулятор не запускается вместе с `npm run demo`: его включают вручную, в двух местах.

1. Запустите API с `DEMO_SIMULATION_ENABLED=true` (иначе заголовок `X-Demo-Source` игнорируется).
2. В другом терминале:

```
DEMO_SIMULATION_ENABLED=true npm run demo:sim
```

В PowerShell: `$env:DEMO_SIMULATION_ENABLED='true'; npm run demo:sim`.
Без переменной команда сразу выходит с кодом 2 и сообщением «Имитация выключена», ничего не создав.
Если переменная есть у команды, но не у API, симулятор остановится после первой записи с тем же сообщением.

## Опции

| Опция | Что делает |
|---|---|
| `--interval <сек>` | пауза между шагами, по умолчанию 8 |
| `--seed N` | зерно генератора: тот же seed и тот же начальный набор данных дают ту же последовательность действий |
| `--max-events N` | остановиться после N шагов |
| `--once` | один шаг (для проверок) |
| `--api-url <адрес>` | адрес API, по умолчанию `http://127.0.0.1:3000`; для `node infra/run-demo.mjs` укажите его порт API |

Пример: `npm run demo:sim -- --once --seed 1`.

## Правила работы

- Только публичное API и демо-пользователи из seed (`X-Demo-User`); к хранилищу симулятор не обращается. Каждый запрос идёт с `X-Demo-Source: simulator`.
- Тексты обращений берутся из seed-датасета, без сети и без LLM.
- Симулятор ведёт только свои обращения (`simulated: true`), seed-обращения не трогает.
- Допустимые переходы статусов берёт из `contracts/api.yaml` (`x-status-transitions`); недопустимых не пробует.
- На ответ 429 ждёт `Retry-After` и повторяет запрос.
- Ctrl+C завершает процесс чисто и печатает итог: сколько подано, взято в работу, отклонено, решено.
- Код выхода: 0 успех, 1 ошибка API (5xx и т. п.), 2 имитация выключена или неверные аргументы.
