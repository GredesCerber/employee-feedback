# Чек-лист сдачи работы (#360)

Дедлайн: **13 ноября 2026, 14:00** (форма закрывается). Отправляем заранее, с запасом не меньше часа: **не позже 13:00**.

Ответственный за отправку: **капитан команды (GredesCerber)**, по [manifest.md](../manifest.md#сдача-работы-условия-организаторов). Название команды: **Caliginous**.

## Поля формы организаторов

Форма: «Сдача работ — хакатон Модус Трейд». Открывается без входа в аккаунт; сохранить ответы можно только войдя в Google.

| № | Поле | Обязательно | Чем заполняем |
|---|---|---|---|
| 1 | Название команды | да | `Caliginous` |
| 2 | Email капитана | да | Email капитана команды. Берёт капитан, в репозиторий не записываем |
| 3 | Ссылка на проект на GitHub (ответ в поле «Пришлите ссылку на проект на github») | да | Ссылка на репозиторий продукта. Видимость репо решает капитан, см. п. «Перед отправкой» |

Текст формы также просит добавить аккаунт `Modus-Trade-Hakaton` в GitHub-репозиторий проекта. Это выдача доступа на чужой аккаунт, поэтому решение за капитаном и отдельно записывается в манифест. Агенты этот доступ не выдают.

## Ссылки, которые уходят в форму или в описание

| Ссылка | Что проверяем | Результат проверки |
|---|---|---|
| Репозиторий GitHub (поле 3) | Открывается без входа в аккаунт (инкогнито). Сейчас репо приватное, см. манифест | не проверено |
| Демо-версия или запись демо (если демо-стенд недоступен) | Открывается без входа, демо-сценарий проходится | не проверено |
| Презентация или PRD (если есть отдельный файл) | Открывается без входа в аккаунт | не проверено |

Проверка: открыть каждую ссылку в режиме инкогнито, записать дату, время и результат в колонку «Результат проверки». Пока колонка пустая, ссылка считается непроверенной.

## Вес вложений

Лимит организаторов: 100 МБ на всё, что прикладываем. Большие файлы (видео, макеты) не прикладываем, даём ссылкой.

## Если демо недоступно

1. Не отправлять форму с нерабочей ссылкой.
2. Использовать записанное видео демо (см. [playbooks/preflight.md](../playbooks/preflight.md), «что показываем, если всё упало»).
3. В описании честно указать, что демо записано, и какие части являются имитацией.
4. Если ни демо, ни видео нет к 13:00, отправлять форму с ссылкой на репо и концепцией. Решение принимает капитан и записывает его в чек-лист.

## Перед отправкой

- [ ] Все три поля заполнены, название команды — `Caliginous`.
- [ ] Ссылки из таблицы проверены, результат записан.
- [ ] Вес вложений не больше 100 МБ.
- [ ] Решение о видимости репозитория принято капитаном и записано (открыть репо или отдать архив жюри без закрытых данных).
- [ ] Форма отправлена один раз, до 14:00; подтверждение сохранено.
- [ ] Время отправки: не позже 13:00.
