# Демо Employee Feedback

## Запуск

Нужны Node.js >=22.12.0 и npm. В корне репозитория:

```sh
npm run demo -- --web-port 5173
```

Открыть http://127.0.0.1:5173. Первая команда устанавливает отсутствующие зависимости
и собирает оба приложения. Docker, база и ключ ИИ для основного сценария не нужны.
Без `--web-port` выбирается свободный порт, адрес выводится в терминале.
`npm run dev` и `npm start` — тот же запуск. Остановка: Ctrl+C.

Перед повторным показом: `npm run demo:reset -- --web-port 5173`.
Этот вариант использует исходный набор в памяти; файл PERSIST_FILE не удаляется.

## Сценарий на 3–5 минут

1. Сотрудник → «Новое обращение»: проблема, категория, описание, решение.
   Можно подать анонимно; место на карте необязательно. Для показа без тайлов
   введите широту 55.01 и долготу 73.37. Отправьте и откройте карточку.
2. Перейдите в «Мои обращения» и вернитесь к последнему обращению.
3. Руководитель → очередь: найдите номер, возьмите в работу,
   запросите уточнение. Сотрудник отвечает; руководитель фиксирует решение.
   Покажите итог сотруднику. Для отказа обязательно мотивированное объяснение.
4. Руководитель: поиск, фильтры, экспорт CSV, уведомления и отмена действия.
5. Администратор: сводка, графики, доля закрытых, сроки и повторяющиеся темы.
6. Переключите RU / EN / KK и светлую / тёмную тему; выбор сохраняется
   при перезагрузке. При смене языка введённый текст сохраняется.

## Что показываем честно

- Данные синтетические, роль выбирается в шапке; корпоративного входа пока нет.
- Вложения — метаданные файла-заглушки.
- Без настроенного хранилища данные живут до остановки API.
- Автокатегория и сводка без ключа ИИ используют локальные правила и шаблон.
- Перевод сообщения запускается только кнопкой и показывается рядом с оригиналом.
  Он требует серверного ANTHROPIC_API_KEY; без ключа явно показана недоступность,
  оригинал остаётся на месте. Ключ хранится только в окружении сервера.
- Тайлы OpenStreetMap требуют сети; ручной ввод координат работает без них.
- Сайт локальный. Общая публичная ссылка требует отдельного размещения.

## Проверки

```sh
npm run build
npm --prefix tests/e2e ci
npm --prefix tests/e2e run e2e:install
```

После запуска демо в другом терминале (PowerShell):

```powershell
$env:E2E_BASE_URL='http://127.0.0.1:5173'
npm run test:e2e
```

Для сдачи исходников: `node infra/make-submission-archive.mjs`.
