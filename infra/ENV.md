# Переменные окружения

Все настройки решения через env собраны здесь. Таблицу сверяет с кодом тест
`tests/acceptance/105-env-docs.test.mjs` (вручную: `node infra/check-env.mjs`).

Правила:

- Читаете в коде новую переменную — добавьте строку в таблицу.
- Переменная ещё не читается кодом, но нужна для будущей задачи — оставьте строку и напишите в «Статус» слово «планируется».
- В `api/.env.example` и `web/.env.example` значения всегда пустые. Секреты и ключи в репозиторий не кладём, только в локальный `.env` (он в `.gitignore`).
- Системные `PATH` и `npm_execpath` выставляют ОС и npm, они здесь не описываются.

Все значения по умолчанию рассчитаны на локальное демо: ни одна переменная не обязательна.

| Переменная | Где используется | По умолчанию | Обязательна | Статус |
|---|---|---|---|---|
| `PORT` | `api/src/server.ts` (порт API); `docker-compose.yml` и `infra/run-demo.mjs` задают его сами | `3000` | нет | используется |
| `HOST` | `api/src/server.ts` (адрес, на котором слушает API); в Docker `0.0.0.0` | `127.0.0.1` | нет | используется |
| `NODE_ENV` | `api/src/rate-limit.ts`: при `test` лимит частоты запросов отключён | не задана | нет | используется |
| `RATE_LIMIT_MAX` | `api/src/rate-limit.ts`: сколько POST/PATCH на пользователя за окно, `0` отключает лимит | `30` | нет | используется |
| `RATE_LIMIT_WINDOW_S` | `api/src/rate-limit.ts`: длина окна лимита в секундах, от 1 | `60` | нет | используется |
| `VITE_API_BASE_URL` | `web/src/api/client.ts`: базовый адрес API, подставляется при сборке Vite; `web/.env.example`; `infra/run-demo.mjs` собирает с `/api` | `/api` | нет | используется |
| `PERSIST_FILE` | файл, куда API сохраняет данные между перезапусками (#92); `infra/run-demo.mjs` уже передаёт его пустым при `--seed-reset` | пусто (данные только в памяти) | нет | планируется (#92) |
| `DEMO_API_PORT` | `infra/serve-demo.mjs`: порт API, на который проксируется `/api`; задаёт `infra/run-demo.mjs` | выбирает `infra/run-demo.mjs` | нет | используется |
| `DEMO_WEB_PORT` | `infra/serve-demo.mjs`: порт собранного веба; задаёт `infra/run-demo.mjs` | выбирает `infra/run-demo.mjs` | нет | используется |
| `WEB_PORT` | `docker-compose.yml`: внешний порт веба в Docker | `8080` | нет | используется |
