# Переменные окружения

Значения задаются в окружении процесса или в панели хостинга. Секретов для
синтетического демо нет. Значения `VITE_*` попадают в публичный JavaScript;
ключи и пароли туда передавать нельзя. Перезапустите API после изменения его env;
после изменения `VITE_API_BASE_URL` пересоберите веб.

| Имя | Где читается | По умолчанию | Обязательность / назначение |
|---|---|---|---|
| `HOST` | `api/src/server.ts` | `127.0.0.1` | На Render обязательно `0.0.0.0` |
| `PORT` | `api/src/server.ts` | `3000` | Необязательна локально; Render передаёт сам |
| `NODE_ENV` | `api/src/rate-limit.ts` | не задано | На хостинге `production`; `test` отключает лимит для тестов |
| `RATE_LIMIT_MAX` | `api/src/rate-limit.ts`, через `integerSetting` | `30` | Неотрицательное целое; `0` отключает лимит |
| `RATE_LIMIT_WINDOW_S` | `api/src/rate-limit.ts`, через `integerSetting` | `60` | Положительное целое, длина окна в секундах |
| `VITE_API_BASE_URL` | `web/src/api/client.ts` | `/api` | Для Vercel прямой HTTPS URL Render API без `/api` и завершающего `/`; публичный адрес, не секрет |
| `NODE_VERSION` | платформа Render, `infra/deploy/render.yaml` | в конфиге `22` | Планируется при ручной выкладке; последняя версия линии 22, код приложения её не читает; требуется Node >=22.12 |
| `CORS_ORIGINS` | планируется в `api/src` (#94) | не задано, CORS выключен | Для отдельных доменов — точные origins через запятую, без пути; применять после принятия #94 |

Для локального запуска `node infra/run-demo.mjs` выбирает порты сам и собирает
веб с `/api`. Переменные внутренних дочерних процессов описаны в справке запуска.
Дополнительные env для CORS (#94) и сохранения (#92) следует сверять с принятым
кодом соответствующих задач: эта конфигурация не включает постоянный диск.
