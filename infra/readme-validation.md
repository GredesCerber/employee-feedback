`tests/acceptance/299-readme-jury.test.mjs` при каждом `hk check`.

- Дата: 12 ноября 2026 г. ОС: Windows 11, Node.js v24.21.0, npm из комплекта Node.

## Основной запуск из чистой папки

```sh
git clone <репозиторий> clean && cd clean
npm run demo -- --api-port 3299 --web-port 5299
```

Порты 3299/5299 взяты вместо 3000/5173, чтобы не мешать другим запущенным стендам; в README указан пример с `--web-port 5173`.

| Проверка | Результат |
|---|---|
| установка зависимостей из lockfile, сборка API и веба | успешно (npm предупредил о postinstall-скрипте esbuild, сборка не пострадала) |
| `GET http://127.0.0.1:5299/api/health` | `200`, `{"status":"ok","version":"0.1.0"}` |
| `GET http://127.0.0.1:5299/` и `/summary` | `200` |
| остановка Ctrl+C | оба процесса остановлены, порты освобождены |

Вариант с Docker Compose в этой проверке не запускался; его покрывает существующий тест
`tests/acceptance/58-docker-compose.test.mjs` (пропускается, если Docker недоступен).

## Скриншоты

```sh
npm --prefix tests/e2e ci
npm run demo -- --api-port 3299 --web-port 5299 --no-install
node infra/screenshots/capture.mjs --base-url http://127.0.0.1:5299
```

Скрипт в Chromium (viewport 1280×860, deviceScaleFactor 2, локаль ru-RU, светлая тема) проходит
демо-путь на синтетических данных: подача → уточнение → ответ автора → решение, затем снимает
семь экранов в `infra/screenshots/` (`01-submit` … `07-dashboard`). Перед повторным снятием
данные сбрасывались `POST /api/demo/reset` от `admin-1`. Все снимки просмотрены вручную:
на экранах только синтетические данные и демо-пользователи.
