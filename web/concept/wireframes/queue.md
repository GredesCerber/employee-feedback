# Макет: Очередь обращений

Узел карты экранов: `queue`. Маршрут: `/queue`. Роль: manager. Шаги демо: 2, 5.

Рабочая область руководителя: фильтры, просроченные, обращения без ответственного (запасная очередь).

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Руководитель manager-1 ▾ ]    │
├──────────────────────────────────────────────────────────────────────┤
│  Очередь обращений                                                   │
│  ┌ Фильтры ───────────────────────────────────────────────────┐      │
│  │ Подразделение [Все ▾]  Категория [Все ▾]  Статус [Все ▾]   │      │
│  │ Очередь [Все | Без ответственного | С ответственным]       │      │
│  │ Срок от [__.__]  до [__.__]   Поиск [номер или текст    ]  │      │
│  │ [x] Только просроченные    [ Применить фильтры ] [Сбросить]│      │
│  └────────────────────────────────────────────────────────────┘      │
│  ┌───────┬────────────────────┬─────────────┬────────┬────────┐      │
│  │ Номер │ Тема               │ Ответствен. │ Статус │ Срок   │      │
│  ├───────┼────────────────────┼─────────────┼────────┼────────┤      │
│  │ A-021 │ Согласование ...   │ —           │ Новое  │ 12.11! │      │
│  │ A-015 │ Пропуска ...       │ Иванова     │ В раб. │ 09.11! │      │
│  └───────┴────────────────────┴─────────────┴────────┴────────┘      │
│  Пусто: «По выбранным фильтрам обращений нет» + «Сбросить»           │
│                                           [ Назад ] [ Далее ]        │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Применить или сбросить фильтры → `queue`
- Нажать номер обращения → `handling`

## Заметки

- Просроченный срок отмечен знаком и цветом, а не только цветом.
- Фильтры сохраняются в адресе страницы.
