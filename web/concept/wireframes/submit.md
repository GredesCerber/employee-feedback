# Макет: Новое обращение

Узел карты экранов: `submit`. Маршрут: `/submit`. Роль: employee. Шаги демо: 1, 2.

Форма подачи (R1): тип, категория, описание, предлагаемое решение, тестовое вложение.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Сотрудник employee-1 ▾ ]      │
├──────────────────────────────────────────────────────────────────────┤
│  Новое обращение                                                     │
│  Сообщите о проблеме или предложите улучшение.                       │
│                                                                      │
│  Тип обращения   (•) Проблема  ( ) Предложение  ( ) Благодарность    │
│  Категория       [ Межотдельное взаимодействие            ▾ ]        │
│  Описание        ┌──────────────────────────────────────────┐        │
│                  │                                          │        │
│                  └──────────────────────────────────────────┘        │
│  Предлагаемое решение (необязательно)                                │
│                  ┌──────────────────────────────────────────┐        │
│                  └──────────────────────────────────────────┘        │
│  [x] Добавить тестовое вложение  sample-request.txt (заглушка)       │
│                                                                      │
│  ⚠ Ошибка у поля: текст под полем, фокус на первом неверном          │
│                                               [ Отправить ]          │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Отправить корректно заполненную форму → `registered`
- Ошибка полей: исправить, значения остаются → `submit`

## Заметки

- Пока идёт отправка, кнопка заблокирована; при ограничении частоты показывается ожидание.
- Для шага 2 выбирают категорию «Категория без ответственного (демо)».
