# Макет: Пользователи и права

Узел карты экранов: `admin`. Маршрут: `/admin`. Роль: admin. Шаги демо: вне обязательных шагов.

Экран позволяет администратору добавлять участников, менять их роли и активность, а также настраивать ответственного и срок для каждой категории. Изменения правил действуют на новые обращения.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Администратор ▾ ]             │
│ Сводка · Дашборд · Пользователи и права                              │
├──────────────────────────────────────────────────────────────────────┤
│ Пользователи и права                                                │
│ Добавляйте участников, меняйте роли и права, деактивируйте учётки    │
│ и настраивайте, кому уходят обращения.                               │
│                                                                      │
│ Добавить участника                                                   │
│ ФИО [________________] Подразделение [Закупки ▾] Роль [Сотрудник ▾] │
│                                                        [ Добавить ]  │
│                                                                      │
│ Пользователи (3)                                                     │
│ ФИО             Подразделение  Роль          Статус      Действие    │
│ Анна Иванова    Закупки        Сотрудник ▾   Активен     [Деактивировать]
│ Илья Петров     Продажи        Руководитель ▾ Активен    [Деактивировать]
│                                                                      │
│ Категории и ответственные                                            │
│ Категория          Ответственный                  Срок ответа, дней  │
│ Обучение           [Илья Петров ▾]                [ 5 ]             │
│ Межотдельное...    [Запасная очередь руководителя ▾] [14]            │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · данные демо хранятся в памяти сервера                  │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- В меню: Сводка → `summary`

## Заметки

- Пример таблицы условный; состав участников и категорий загружается с сервера.
- Ошибка загрузки предлагает повторить запрос. Ошибки сохранения показываются на странице.
- Администратор не получает доступ к очереди руководителя через этот экран.
