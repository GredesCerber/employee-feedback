# Макет: Сводка

Узел карты экранов: `summary`. Маршрут: `/summary`. Роль: admin. Шаги демо: 6.

Обзор для администратора: обращения по типам, доля закрытых, среднее время первого ответа, повторяющиеся темы.

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Обновить сводку → `summary`
- В меню: Пользователи и права → `admin`
- Для очереди сменить роль на руководителя → `roles`

## Заметки

- Цифры на макете условные.
- «Открыть в очереди» — дополнительный переход через смену роли, не входит в обязательный шаг 6.
