# Макет: Демонстрационная роль (общая шапка)

Узел карты экранов: `roles`. Маршрута нет, это часть шапки. Роль: employee, manager, admin. Шаги демо: все шаги: смену роли делает ведущий.

Общая шапка на каждом экране. Переключатель роли — **имитация входа**, а не авторизация: сервер получает заголовок `X-Demo-User` и сам проверяет права.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Сотрудник employee-1 ▾ ]      │
├──────────────────────────────────────────────────────────────────────┤
│   ┌──────────────────────────────┐                                   │
│   │ Роль ▾                       │                                   │
│   │ ○ Сотрудник  employee-1      │  → «Мои обращения»                │
│   │ ○ Сотрудник  employee-2      │                                   │
│   │ ○ Руководитель manager-1     │  → «Очередь»                      │
│   │ ○ Администратор admin-1      │  → «Сводка»                       │
│   └──────────────────────────────┘                                   │
│   Подпись: «Имитация входа — выбор роли для демонстрации»            │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Выбрать сотрудника → `mine`
- Выбрать руководителя → `queue`
- Выбрать администратора → `summary`
- О прототипе в нижней панели → `about`

## Заметки

- Шапка видна на всех экранах, поэтому стрелки «Сменить демонстрационную роль» с карточек ведут сюда.
- После смены роли `/` открывает рабочую область роли; чужой маршрут возвращает в свою область.
