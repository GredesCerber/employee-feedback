# Макет: Обращение зарегистрировано (состояние формы)

Узел карты экранов: `registered`. Маршрут: `/submit`. Роль: employee. Шаги демо: 1.

Состояние экрана `/submit` после успешной отправки: присвоенный номер и следующий шаг. Отдельной страницы нет.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Сотрудник employee-1 ▾ ]      │
├──────────────────────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────────────────────┐      │
│  │ ✓ Отправлено                                               │      │
│  │   Обращение зарегистрировано: A-0XX                        │      │
│  │   Ответственный: Руководитель закупок · срок: 14.11        │      │
│  │   Следующий шаг: ответственный рассмотрит обращение        │      │
│  │                                                            │      │
│  │   [ Открыть обращение ]     [ К моим обращениям ]          │      │
│  └────────────────────────────────────────────────────────────┘      │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Открыть обращение → `author`
- К моим обращениям → `mine`

## Заметки

- Если ответственного нет, вместо имени — «Запасная очередь руководителя» (шаг 2).
