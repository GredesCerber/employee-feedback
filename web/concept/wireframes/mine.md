# Макет: Мои обращения

Узел карты экранов: `mine`. Маршрут: `/my`. Роль: employee. Шаги демо: 1, 3, 4.

Список обращений текущего сотрудника со статусом и сроком. Чужие обращения здесь не видны.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Сотрудник employee-1 ▾ ]      │
├──────────────────────────────────────────────────────────────────────┤
│  Мои обращения                              [ + Новое обращение ]    │
│  ┌────────┬──────────────────────────┬───────────────┬──────────┐    │
│  │ Номер  │ Тема                     │ Статус        │ Срок     │    │
│  ├────────┼──────────────────────────┼───────────────┼──────────┤    │
│  │ A-021  │ Согласование заявок ...  │ Нужно уточн.  │ 14.11    │    │
│  │ A-017  │ Доступ к складу ...      │ Решено        │ —        │    │
│  │ A-009  │ Предложение: шаблон ...  │ Отказ         │ —        │    │
│  └────────┴──────────────────────────┴───────────────┴──────────┘    │
│  Пусто: «Обращений пока нет» + кнопка «Новое обращение»              │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Новое обращение → `submit`
- Нажать номер своего обращения → `author`

## Заметки

- Статус «Нужно уточнение» выделен, чтобы автор сразу видел, что от него ждут ответа (шаг 3).
