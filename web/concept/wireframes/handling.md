# Макет: Карточка руководителя

Узел карты экранов: `handling`. Маршрут: `/queue/:complaintId`. Роль: manager. Шаги демо: 2, 3, 4, 5.

Обработка обращения: назначение, статусы, запрос уточнения, решение или мотивированный отказ.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Руководитель manager-1 ▾ ]    │
├──────────────────────────────────────────────────────────────────────┤
│  ← К очереди                                [ Обновить карточку ]    │
│  A-021 · Проблема · Межотдельное взаимодействие      [В работе]      │
│  Ответственный: —   Срок: 12.11 (просрочено)                         │
│  ┌ Назначение ────────────────────────────────────────────────┐      │
│  │ [ Выберите руководителя ▾ ]                  [ Назначить ] │      │
│  └────────────────────────────────────────────────────────────┘      │
│  ┌ Статус и обсуждение ───────────────────────────────────────┐      │
│  │ Статус [ На рассмотрении ▾ ]                               │      │
│  │ Комментарий или вопрос ┌────────────────────────────────┐  │      │
│  │                        └────────────────────────────────┘  │      │
│  │ [ Добавить комментарий ]  [ Запросить уточнение ]          │      │
│  └────────────────────────────────────────────────────────────┘      │
│  ┌ Завершение ────────────────────────────────────────────────┐      │
│  │ Итог (•) Решено ( ) Отказ                                  │      │
│  │ Итог рассмотрения (обязательно) ┌──────────────────────┐   │      │
│  │ Дальнейшие действия             └──────────────────────┘   │      │
│  │                                       [ Сохранить итог ]   │      │
│  └────────────────────────────────────────────────────────────┘      │
│  Комментарии · История обращения (как в карточке автора)             │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Назначить, изменить статус, запросить уточнение или сохранить итог → `handling`
- К очереди → `queue`
- Сменить демонстрационную роль → `roles`

## Заметки

- Итог без пояснения не сохраняется: ошибка у поля (шаг 4).
- Тот же компонент, что карточка автора, но с другим маршрутом и набором действий.
