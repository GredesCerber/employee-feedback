# Макет: Карточка автора

Узел карты экранов: `author`. Маршрут: `/my/:complaintId`. Роль: employee (автор обращения). Шаги демо: 1, 2, 3, 4.

Автор видит, где его обращение и чем всё закончилось: статус, срок, ответственный, переписка, итог.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Обратная связь «Модус Трейд»   Роль: [ Сотрудник employee-1 ▾ ]      │
├──────────────────────────────────────────────────────────────────────┤
│  ← К моим обращениям                                                 │
│  A-021 · Проблема · Межотдельное взаимодействие  [Нужно уточнение]   │
│  Следующий шаг: ответьте на вопрос руководителя                      │
│  Ответственный: Руководитель закупок   Создано: 10.11   Срок: 14.11  │
│  ── Описание ─────────────────────────────────────────────────       │
│  ...                                                                 │
│  ── Тестовые вложения: sample-request.txt (только сведения) ──       │
│  ── Итог рассмотрения ────────────────────────────────────────       │
│  Решено / Отказ: объяснение и дальнейшие действия                    │
│  ── Комментарии ──────────────────────────────────────────────       │
│  Руководитель: «Уточните, какие заявки задерживаются?»               │
│  Ваш ответ на уточнение ┌─────────────────────────────┐              │
│                         └─────────────────────────────┘              │
│                                    [ Ответить на уточнение ]         │
│  ── История обращения ────────────────────────────────────────       │
│  10.11 Создано · 10.11 Назначено · 11.11 Запрошено уточнение         │
├──────────────────────────────────────────────────────────────────────┤
│ О прототипе · все данные синтетические                               │
└──────────────────────────────────────────────────────────────────────┘
```

## Переходы

Подписи совпадают со стрелками в [карте экранов](../../../design/flows/screen-map.md).

- Ответить на уточнение: обновляется история → `author`
- К моим обращениям → `mine`
- Сменить демонстрационную роль → `roles`

## Заметки

- Блок «Итог рассмотрения» появляется только после решения или отказа (шаг 4).
- Поле ответа видно только при статусе «Нужно уточнение».
