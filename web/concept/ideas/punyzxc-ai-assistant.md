# Идея: ИИ-помощник для сотрудника и ответственного

- **Автор:** punyzxc
- **Тип:** функция

## Проблема
Сотрудник не знает, в какую категорию отнести проблему, и пишет обращение без нужных деталей; потом уходят дни на уточнения (A-001: «не хватает назначения изделия и параметров», A-015: поручения без результата и срока). Ответственному нужно быстро понять суть и ответить, а руководителю увидеть повторы (ТЗ п. 1.3: «сокращение ручных операций», «выявление повторяющихся проблем»).

## Идея
Встроенный помощник (демо на быстрой модели, например Gemini Flash через API) в четырёх местах:
1. **В форме подачи:** подсказывает категорию и подразделение (это питает маршрутизацию R2), задаёт 1-2 уточняющих вопроса, если не хватает данных, и помогает сформулировать «предполагаемое решение».
2. **Похожие обращения:** до отправки показывает уже поданные похожие, чтобы не плодить дубли и поддержать сводку повторов (R7).
3. **Черновик ответа ответственному:** предлагает текст запроса уточнения или мотивированного отказа (R3, R4); человек правит и отправляет сам.
4. **Навигация и справка:** «где мои обращения», «что значит статус», «кто рассматривает».

Помощник только предлагает, все решения и отправку делает человек.

## Проверка по манифесту
- Связь с ТЗ (пункт): 1.3, 2.4 (категоризация, уточнения), 2.5 (выявление повторов), 2.7; R1, R2, R3, R4, R7.
- Можно показать на синтетических данных: да, на текстах датасета.
- В MVP или в развитие, почему: **в MVP как демо-режим** с записанными ответами модели на обращения датасета (подсказка категории и черновик ответа) с явной пометкой «демо ИИ» (R12). **Живой вызов API и навигация по сайту в развитие**, после решения по безопасности данных.

## Риски и допущения
- **Расхождение с ТЗ.** ИИ в ТЗ не упоминается; ценность есть только как ускорение подачи, маршрутизации и ответа. Не должен вытеснять ядро MVP.
- **Безопасность данных (п. 3.5).** Отправка текстов обращений во внешний зарубежный API для настоящей компании под вопросом; для промышленной версии нужен согласованный провайдер или своя модель. На демо только синтетика.
- **Доступность.** API Google может быть недоступен из РФ без обходных путей; ключ API получает человек, ключ хранится только в `.env`, не в коде (AGENTS.md).
- **Тесты.** По AGENTS.md вызовы LLM в тестах только через записанные фикстуры, без сети, поэтому демо-режим на фикстурах совпадает с правилами.
- Выбор стека и провайдера за задачей T32 и капитаном.
