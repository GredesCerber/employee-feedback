# Сводка администратора (#56)

Запустите сервер и фронтенд по [README](README.md), выберите демонстрационную роль «Администратор». `/summary` обращается к настоящему `GET /summary` с `X-Demo-User: admin-1`.

Показываются общее число обращений, количество по типам, доля закрытых, среднее время первого ответа и повторяющиеся категории с числом обращений. Доля из API (0–1) форматируется в проценты; время уже дано сервером в часах. `null` означает отсутствие первых ответов и отображается как «Нет ответов». Категории и показатели не пересчитываются из текущей страницы очереди: используются серверные агрегаты по всему набору.

Экран различает загрузку, пустые данные и ошибку; при ошибке нет фиктивных показателей, доступен повтор. Кнопка обновления запрашивает новый согласованный снимок. Время снимка отображается в часовом поясе браузера. Сводка доступна только через меню администратора; сервер отдельно проверяет роль.

Проверки: `web/tests/summary.test.tsx` и `tests/acceptance/56-admin-summary.test.mjs`, полный `hk check` и `npm --prefix web run build`.
