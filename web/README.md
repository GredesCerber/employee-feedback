# Фронтенд

Node.js 22.12+ и npm. Из корня репозитория:

```sh
npm --prefix web ci
npm --prefix web run test
npm --prefix web run build
npm --prefix web run dev
```

Vite открывает приложение на http://localhost:5173. Dev-прокси передаёт `/api/*` на `http://localhost:3000/*`; путь контракта `/complaints` остаётся `/complaints` на сервере. Для другой среды задайте `VITE_API_BASE_URL` (без завершающего `/`). В production нужен прокси `/api` и fallback маршрутов приложения на `index.html`; `vite preview` предназначен только для локальной проверки сборки.

Каркас #50: маршруты `/my`, `/submit`, `/queue`, `/summary`, переключение роли, меню и типизированный клиент. Бизнес-экраны добавляют отдельные задачи #54–#56; сейчас разделы явно отмечены как ещё не запущенные. Выбор роли — демонстрация, не защищённый вход. Сервер получает `X-Demo-User` и самостоятельно проверяет права; скрытие пунктов меню не заменяет авторизацию.

`useSession()` предоставляет текущую роль и API-клиент. При смене роли создаётся новый клиент и сбрасывается дерево страницы, чтобы не переносить данные предыдущей роли. Ошибки API возвращаются как `ApiError`: HTTP-код, код контракта, сообщение и ошибки полей. Сетевые ошибки имеют код `NETWORK_ERROR`.

Типы в `src/api/schema.d.ts` генерируются из принятого `contracts/api.yaml`. Не редактировать вручную:

```sh
npm --prefix web run api:generate
npm --prefix web run api:check
```

`npm run test` проверяет актуальность типов и запускает Vitest/Testing Library. Приёмочный вход `tests/acceptance/50-web-shell.test.mjs` запускает тот же набор в полном `hk check`. Запросы в тестах подменяются локальными ответами, сеть не требуется. Стили оболочки находятся в `src/shell.css`; каталог `src/styles/` оставлен для команды дизайна.
